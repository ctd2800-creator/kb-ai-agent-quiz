# KB AI Agent 모의고사

2026 KB디지털역량진단 AI Agent 개발 교재의 학습 범위를 바탕으로 만든 4지선다 300문제 퀴즈입니다. 문항과 해설은 교재를 옮긴 것이 아니라 개념을 확인하기 위해 새로 작성했습니다.

- 1–42: LLM·AI 개론
- 43–85: 프롬프트 엔지니어링
- 86–128: RAG
- 129–171: Tool Use
- 172–214: Agent 아키텍처
- 215–257: 프레임워크·워크플로우
- 258–300: 운영·보안·거버넌스

규제·조항 관련 문항은 개념 확인용이며 법률 자문이 아닙니다. 최신 원문과 준법 검토를 기준으로 합니다.

로컬에서는 `index.html`을 브라우저로 열면 됩니다. 문항을 고친 뒤에는 `python build.py`로 다시 만듭니다.
